# Demo y capturas — Actividad 6

1. Inicie con `VITE_USE_MOCKS=false`; ingrese como `admin@demo.com` / `Demo1234`.
2. Abra **Administración > Servicios**, pulse el icono de lista de un servicio y capture `01-listado.png`.
3. Escriba “Requisito de demostración” y guarde; capture `02-crear.png` y `03-creado.png`.
4. Pulse lápiz, cambie el texto a “Requisito actualizado”, guarde; capture `04-editar.png` y `05-editado.png`.
5. Pulse papelera del requisito de demostración; capture antes/después como `06-eliminar.png`.
6. Intente guardar con título vacío; capture el mensaje “El título del requisito es obligatorio.” como `07-validacion.png`.

Guarde las capturas en `docs/evidencias/actividad6/`. El flujo usa PostgreSQL real solo con Docker activo y no debe ejecutarse en modo mocks.
