# Evidencias de JustiTurno

**7 de noviembre de 2026.** La carpeta [actividad7](actividad7/) contiene diez capturas del servicio público en Render, su [manifiesto](actividad7/manifest.json) y [48 comprobaciones de citas y adjuntos](actividad7/flujo-citas.json). Se repitieron el flujo de festivos, el CRUD, el login por rol y la verificación en seis tamaños sobre el origen HTTPS.

## Vista previa del 5 de noviembre

Las 4 capturas de actividad4 y las 7 de actividad6 se obtuvieron con Chromium sobre la **vista previa local de Workers**. El estado de éxito usó Nager.Date real; carga, vacío y error se provocaron desde Playwright. El CRUD administrativo usó PostgreSQL y se comprobó con recargas. Ninguna captura se presenta como evidencia pública de la actividad7.

Se ejercitaron las dimensiones 1440×900, 1024×768, 768×1024, 430×932, 390×844 y 375×812. El control de desbordamiento compara `scrollWidth` y el ancho del viewport.
